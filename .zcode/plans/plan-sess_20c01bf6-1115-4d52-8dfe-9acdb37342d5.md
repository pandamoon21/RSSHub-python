# 智通财经 theme 类 RSS 节点

## 目标
新增智通财经主题列表 RSS 节点，路径形如 `/zhitongcaijing/theme/<theme_id>`，把示例页 `https://www.zhitongcaijing.com/theme/detail/20.html` 下的文章聚合成 Atom 输出。

## 页面与接口分析（已用 Playwright + 直连验证）

- **入口页** `https://www.zhitongcaijing.com/theme/detail/{theme_id}.html`
  - 主题名：`.hadknown-title`
  - 列表容器：`#news-article-box .info-list-item`
    - `.info-item-content-title a` → 标题 + `/content/detail/<id>.html` 链接
    - `.info-item-content-desc` → 摘要
    - `.info-item-content-operat span` → 短日期 `MM-DD`
  - 容器自带 `data-reach-bottom="/theme/article-list.html?&id=20"`、`data-page="2"`，提示滚动加载接口
- **增量 JSON 接口** `GET https://www.zhitongcaijing.com/theme/article-list.html?id={theme_id}&page={n}`
  - 返回 `{"status":"success","data":{"list":[{content_id,title,digest,image,create_time(秒),create_time_desc,url}, ...]}}`
  - 每页 ≈20 条；末页返回空数组，无上限封顶
  - 异常 id 会 5xx（id=100 验证 → 500），需安全降级
- 现有项目里没有 `zhitongcaijing` 目录；`infoq/topic.py`、`readhub/topic.py`、`ctolib/topics.py` 是同类参考实现

### 新建 `rsshub/spiders/zhitongcaijing/theme.py`
```python
import json
import arrow
import requests
from rsshub.utils import DEFAULT_HEADERS

domain = 'https://www.zhitongcaijing.com'
API = f'{domain}/theme/article-list.html'

REQUEST_TIMEOUT = 8
PAGE_LIMIT = 2  # 默认前 2 页，约 40 条


def _fetch_page(theme_id, page):
    res = requests.get(
        API,
        params={'id': theme_id, 'page': page},
        headers=DEFAULT_HEADERS,
        timeout=REQUEST_TIMEOUT,
    )
    res.raise_for_status()
    payload = res.json()
    return payload.get('data', {}).get('list') or []


def parse(post):
    pub = post.get('create_time')
    pub_iso = arrow.get(int(pub)).isoformat() if pub else post.get('create_time_desc', '')
    link = post.get('url') or f"/content/detail/{post.get('content_id')}.html"
    if link.startswith('/'):
        link = f"{domain}{link}"
    parts = [p.get('digest') or '']
    if post.get('image'):
        parts.append(f"<br><img referrerpolicy='no-referrer' src='{post['image']}'>")
    return {
        'title': (post.get('title') or '').strip(),
        'description': ''.join(parts),
        'link': link,
        'pubDate': pub_iso,
        'author': '智通财经',
    }


def ctx(theme_id=''):
    items, errors = [], []
    for page in range(1, PAGE_LIMIT + 1):
        try:
            posts = _fetch_page(theme_id, page)
        except Exception as e:
            errors.append(f'page {page}: {e}')
            break
        if not posts:
            break
        for post in posts:
            try:
                items.append(parse(post))
            except Exception as e:
                errors.append(f'item skip: {e}')
    return {
        'title': f'智通财经 - 主题 {theme_id}',
        'link': f'{domain}/theme/detail/{theme_id}.html',
        'description': '智通财经主题聚合' + ('（部分页面获取失败）' if errors else ''),
        'author': 'hillerliao',
        'items': items,
    }
```

要点：
- 复用既有 `DEFAULT_HEADERS`，不改 utils
- 默认 2 页 ≈40 条；末页数组空就 `break`，避免无效请求
- 单条解析失败跳过，整页失败则 `description` 标注、不抛出（参考 readhub/topic 健壮性）
- 时间优先 `create_time`（秒）→ `arrow` ISO；缺失时回退 `create_time_desc`

### 改 `rsshub/blueprints/main.py`
在合适位置（与 `weiyangx/tag`、`eastmoney` 同类的财经分区，按字母顺序邻近处）插入：

```python
@bp.route('/zhitongcaijing/theme/<string:theme_id>')
@cache.cached(timeout=3600)
def zhitongcaijing_theme(theme_id=''):
    from rsshub.spiders.zhitongcaijing.theme import ctx
    return render_template('main/atom.xml', **filter_content(ctx(theme_id)))
```

要点：
- 路由形态 `/zhitongcaijing/theme/20` 与示例页语义一致

## 不做的事

- 不抓正文（只摘要 + 链接）
- 不支持无限翻页（成本与稳定性权衡，2 页足够 RSS 订阅量）
- 不引入新缓存中间件或 utils 改动
- 不增加单测（项目惯例，新节点无单测）
