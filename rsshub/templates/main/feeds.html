Google News Search

Google News Search

Example: https://pyrsshub.vercel.app/google/news/火了|财富密码|流量密码?site=36kr.com&when=7d

Route: /google/news/:keyword

Parameter:

  • q Keywords; separate multiple terms with | or , (can also be placed in the path)
  • site Restrict to sites; separate multiple with | or ,, e.g. 36kr.com,ithome.com
  • intitle Whether keywords match titles only; defaults to 1, pass 0 to match the full text
  • exclude Exclude terms; separate multiple with |
  • when Time range, e.g. 24h / 7d / 1m
  • hl Language, defaults to zh-CN; gl region, defaults to CN
  • ceid Locale identifier; when omitted it is derived from gl + hl, e.g. CN:zh-Hans
  • dedup Dedup strategy: title (default) / title+source / guid / link / none
  • similar Fuzzy title-dedup threshold (0-1, e.g. 0.9); disabled by default
  • source Whether to keep the trailing " - Publisher" suffix; defaults to 1, pass 0 to strip it
  • sort Sort by publish time descending; defaults to 1

Note: a Google News guid is a story-cluster ID, so the same article re-crawled gets a different guid; and link is a unique redirect per entry, so neither removes duplicates. The default therefore dedups by normalized title (ignoring punctuation, case and full/half-width differences, keeping the newest copy).

Random Line by hillerliao

Example: https://pyrsshub.vercel.app/randomline

Custom CSV: https://pyrsshub.vercel.app/randomline?url=https://raw.githubusercontent.com/HenryLoveMiller/ja/refs/heads/main/cai-gen-tan.csv

Specify title column: https://pyrsshub.vercel.app/randomline?title_col=1

Include context: https://pyrsshub.vercel.app/randomline?include_context=true

Route: /randomline

Parameter:

  • url Optional, custom file URL; can be a CSV/TXT/PDF file or a regular web page (text is extracted automatically); defaults to the RAZ data on GitHub.
  • title_col Optional, 0-based index of the column to use as the title; defaults to the first column.
  • delimiter Optional, delimiter (tab for a tab, newline for a newline, double_newline for 1 blank line, triple_newline for 2 blank lines, quadruple_newline for 3 blank lines, quintuple_newline for 4 blank lines), or a custom delimiter (e.g. ---, ***); defaults to comma.

  • include_context Optional, whether to include the previous and next lines; when set to true the description shows the lines surrounding the selected content; defaults to false.

Description: Pick a random line (or block) from a file or web page to generate an RSS item. For web pages the body text is extracted automatically and split by newlines. Example: https://pyrsshub.vercel.app/randomline?min_length=50&url=https://www.gushiwen.cn/guwen/bookv_c89d8eda4c2d.aspx

Features: supports CSV/TSV/TXT/PDF/EPUB/MOBI and regular web pages; intelligently detects paragraphs (p tags) and headings, preserves paragraph integrity and shows the containing section; built-in high-accuracy PDF parsing with CJK mojibake repair; SWR caching.
